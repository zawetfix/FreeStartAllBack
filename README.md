# Сброс пробного периода StartAllBack до 100 дней ✅

**Скачай ZIP выше "FreeStartAllBack.7z" ** - все файлы в комплекте!

### Что делает сервис:
**Удаляет ключ реестра** где StartAllBack хранит дату окончания триала. Программа создает новый ключ с 100 днями.

### Инструкция:

1. Открой Procmon.exe из папки ProcessMonitor
2. Нажми 6-ю иконку сверху или Ctrl+L
3. Настрой фильтры: https://github.com/zawetfix/FreeStartAllBack/blob/main/N1.png
4. Запусти StartAllBack (уже установленный)
5. Пролистай вниз, найди процессы StartAllBack: https://github.com/zawetfix/FreeStartAllBack/blob/main/N2.png
6. ПКМ по процессу → Properties → Copy ALL
7. Создай .txt на рабочем столе, вставь Ctrl+V, скопируй "Path": https://github.com/zawetfix/FreeStartAllBack/blob/main/N4.png
8. ПКМ "Сброс пробных 100 дней.bat" → Edit
   Замени "ВАШ СКОПИРОВАННЫЙ ПУТЬ КОТОРЫЙ НАЧИНАЕТСЯ С HKCU" на свой
   Ctrl+S, закрой
9. ПКМ по батнику → Запуск от имени администратора
   Нажми E → файл удалится, триал = 100 дней!
