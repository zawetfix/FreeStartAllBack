## 🇺🇸 Instructions in English (EN)

**Reset StartAllBack Trial Period to 100 Days**

**Download the ZIP above "EN_FreeStartAllBack.7z"** - all files included!

### What the service does:
**Deletes the registry key** where StartAllBack stores the trial end date.  
The program will automatically create a new key with 100 days.

### Instructions:

1. Open **Procmon.exe** from the **ProcessMonitor** folder.
2. Click the 6th icon from the top or press **Ctrl+L**.
3. Set up filters: ![Filter setup](https://github.com/zawetfix/FreeStartAllBack/blob/main/N1.png)
4. Launch **StartAllBack** (already installed).
5. Scroll down, find StartAllBack processes: ![Processes](https://github.com/zawetfix/FreeStartAllBack/blob/main/N2.png)
6. Right-click the process → **Properties** → **Copy ALL**.
7. Create a **.txt** file on your desktop, paste **Ctrl+V**, copy the **"Path"**: ![Path copy](https://github.com/zawetfix/FreeStartAllBack/blob/main/N4.png)
8. Right-click **"Reset trial 100 days.bat"** → **Edit**.  
   Replace **"YOUR COPIED PATH STARTING WITH HKCU"** with yours.  
   **Ctrl+S**, close.
9. Right-click the batch file → **Run as administrator**.  
   Press **E** → file will be deleted, trial = 100 days!

**DONE!**

**Works as of: 05/08/2026**

## 🇷🇺 Инструкция на русском (RU)

# Сброс пробного периода StartAllBack до 100 дней

**Скачай ZIP выше "RU_FreeStartAllBack.7z"** - все файлы в комплекте!

### Что делает сервис:
**Удаляет ключ реестра** где StartAllBack хранит дату окончания триала.  
Программа автоматически создаст новый ключ с 100 днями.

### Инструкция:

1. Открой **Procmon.exe** из папки **ProcessMonitor**.
2. Нажми 6-ю иконку сверху или **Ctrl+L**.
3. Настрой фильтры: ![Фильтры](https://github.com/zawetfix/FreeStartAllBack/blob/main/N1.png)
4. Запусти **StartAllBack** (уже установленный).
5. Пролистай вниз, найди процессы StartAllBack: ![Процессы](https://github.com/zawetfix/FreeStartAllBack/blob/main/N2.png)
6. ПКМ по процессу → **Properties** → **Copy ALL**.
7. Создай **.txt** на рабочем столе, вставь **Ctrl+V**, скопируй **"Path"**: ![Путь](https://github.com/zawetfix/FreeStartAllBack/blob/main/N4.png)
8. ПКМ **"Сброс пробных 100 дней.bat"** → **Edit**.  
   Замени **"ВАШ СКОПИРОВАННЫЙ ПУТЬ КОТОРЫЙ НАЧИНАЕТСЯ С HKCU"** на свой.  
   **Ctrl+S**, закрой.
9. ПКМ по батнику → **Запуск от имени администратора**.  
   Нажми **E** → файл удалится, триал = 100 дней!
